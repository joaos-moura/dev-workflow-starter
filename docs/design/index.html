05 · Arquitetura

Backstage → GitHub → OIDC → AWS, sem nenhuma chave guardada.

O pedido nasce no Backstage, que cria o repositório no GitHub. O Actions assume um papel temporário via OIDC. Na conta Dev, o Terraform sobe o site e a API.

11 · Como usar

Do template ao preview em seis passos.

  1. Gere o repositórioPelo GitHub ou pelo workflow novo-projeto.
  2. Abra no devcontainerDependências e Terraform prontos. Fora dele: Node 22.
  3. Abra um pull requestCI roda lint, teste e build; reviewdog comenta o ESLint.
  4. Defina AWS_ROLE_ARNO workflow comenta o plan e publica o preview em pr-<n>.
  5. Faça o mergeAplica o workspace dev e publica o Pages.
  6. Feche o PRO workspace do preview é destruído.
terminalbash
# fora do devcontainer
npm ci
npm run dev

# habilita os jobs da AWS
gh variable set AWS_ROLE_ARN \
  --body "arn:aws:iam::<conta>:role/<repo>"

Nada é criado na AWS enquanto a variável AWS_ROLE_ARN não existir.
