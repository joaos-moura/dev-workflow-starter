# Prova do e2e/movimento.e2e.ts contra o CSS do 32cfce7 (antes do #12)

Só o CSS muda. Os testes e o restante do src ficam os da HEAD, porque
e2e/movimento.e2e.ts não existia naquele commit.

## Reproduzir a falha

    git show 32cfce7:src/styles.css > src/styles.css
    npm run build
    npm run test:e2e -- e2e/movimento.e2e.ts
    echo exit=$?
